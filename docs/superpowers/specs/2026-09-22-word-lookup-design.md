# 点词查询：本句释义与音标

状态：增量设计；“按需查询＋缓存”方向已由用户认可。2026-09-23 已完成小范围技术验证，正式 API 与界面尚未实现，结果见[实验记录](../../experiments/2026-09-23-word-lookup-spike.md)。

基线：[MVP 产品设计](2026-09-16-english-sentence-analysis-mvp-design.md)。本次扩展保持原有四色分析和整句翻译，语法粒度功能已暂缓。

## 1. 用户目标与范围

用户在已经分析的英文结果中点击一个单词，看到该位置的中文释义、对应音标，以及必要时的原形。首次点击查询，重复点击优先使用当前页面缓存，不重新分析整句。

首版支持桌面点击、手机点按和键盘操作。发音播放、收藏、学习历史、划选短语及批量预查不在本期。

必须按具体位置理解单词：`I saw a saw.` 的第一个 `saw` 是“看见”，第二个是“锯子”。通用词典释义不能冒充本句释义；不能仅以单词字符串缓存上下文结果。

## 2. 数据来源建议与验证记录

推荐组合：**FreeDictionaryAPI.com 提供词典候选和音标；现有 DeepSeek 结合原句、位置及候选内容生成本句中文释义，并选择有依据的读音。** 数据源通过独立适配器接入，UI 不依赖供应商响应结构。

官方依据：

- [FreeDictionaryAPI.com 官方说明](https://freedictionaryapi.com/)：无需 API key；提供结构化词典数据及来源；限额为每 IP 每小时 1,000 次。数据来源为 Wiktionary，按页面注明的 CC BY-SA 4.0 与署名要求处理，在浮窗显示服务名称、原词条和许可链接。
- [官方 OpenAPI](https://freedictionaryapi.com/api/v1/openapi.json)：`GET /entries/{language}/{word}` 返回词条、词性、发音候选、词形和释义。仅使用 `type=ipa` 的发音候选，不把其他记音格式当作 IPA。

2026-09-22 在当前环境直接调用官方接口的小样记录：

| 查询 | 结果 | 用途 |
| --- | --- | --- |
| left | 200，有音标和多个词条 | 同形多义 |
| went | 200，有音标和词形字段 | 不规则过去式 |
| bought | 200，有音标和词形字段 | 不规则过去式 |
| read | 200，包含多种音标 | 上下文读音选择 |
| saw | 200，有名词和动词词条 | 同句不同位置 |
| don't | 200，有音标 | 缩约形式 |
| well-known | 200，有音标 | 连字符词 |
| qzxnotaword | 200，entries 为空 | 未收录处理，不能只看 HTTP 状态 |

7 个收录词返回耗时约 0.39–3.08 秒。这些初始结果只证明上述请求当时可用及字段存在。次日组合验证覆盖 20 个上下文位置，发现同词义发音缺失、网络波动及模型增加无依据解释等情况，详见实验记录；长期可用性和正式部署延迟仍需验证。

另两个候选未选用：

- [dictionaryapi.dev](https://dictionaryapi.dev/)：本次 8 个请求均未拿到数据，表现为超时或连接重置；这是当前环境的观察，不代表该服务全球不可用。
- [有道词典 API 官方文档](https://ai.youdao.com/DOCSIRMA/html/dictionary/api/ydcd/index.html)：需要申请接入，页面明确限制缓存，因此不直接采用它来实现当前已选的缓存方案。

## 3. 交互行为

1. 仅已完成分析的英文结果支持点词。点击立即显示加载浮窗，不清空原有结果。
2. 成功时显示原词、简短的本句中文对应词或词组、音标。释义不额外添加语法讲解或原句无法确定的细分限制。原形为可选补充，仅在有依据且与原词不同时显示；缩约、缩写、代词不另列原形。先筛选与本句词义、词性、时态及当前词形匹配的音标，再优先采用有明确英国读音标记的常用候选，其次美国读音；没有口音信息时只标“音标”，不猜测口音。
3. 数据源可能含方言、旧读法和多个同形词。不能直接选第一个音标，也不能把原形音标作为变形词音标。候选保留词条、词义、词形和发音标签的关联，不展平成无语义的 IPA 列表。模型只能选择服务端提供的候选 ID，最终音标由服务端从候选中取回。ID 存在只能保证来源，不能证明上下文选择正确，因此验收还要人工核对读音。
4. 无可靠音标时返回空值，显示“暂无可靠音标”；不得让模型凭空补写 IPA。中文释义仍可单独展示。
5. 点击另一个词更新浮窗；点击空白处、关闭按钮或 Esc 关闭。键盘 Enter/Space 可打开，关闭后焦点返回对应词；手机浮窗始终保持在可视范围内。
6. 开始新的整句分析、替换结果或卸载组件时，关闭浮窗并使旧请求失效。A 请求晚于 B 返回时，不能覆盖 B，也不能把已关闭的浮窗重新打开。
7. 查询失败仅影响浮窗，显示可重试提示。原文、四色标注及整句翻译均保留。

## 4. 单词与位置规则

- 从完整 `result.original` 确定单词范围，再与着色区间组合；标注边界即使落在词内，也应查询完整词。
- 连在字母之间的撇号和连字符保留，例如 `don't`、`John’s`、`well-known`。外层引号、句末标点不属于查询词；纯数字和独立标点不可查询。
- 使用 JavaScript UTF-16 字符串偏移，与现有分析坐标一致。英文结果区域的 `textContent` 点击前后必须严格等于原句，浮窗放在该区域之外。
- 查询规范化与显示文本分开：可在查询副本中规范化弯引号，不改原文；不盲目合并 `US` 与 `us`。
- 单个查询词最多 80 个 UTF-16 单位；超出时只提示暂不支持该词形，不请求外部服务。

## 5. 查询接口与处理流程

在现有 Next.js 项目中新增 `POST /api/word`，请求严格限定为：

```json
{
  "sentence": "I saw a saw.",
  "word": "saw",
  "start": 8,
  "end": 11
}
```

服务端检查：句子非空且不超过 500 字符；词长在范围内；start/end 为合法整数且落在原句内；`sentence.slice(start, end) === word`；该区间必须是可查询的完整词边界。此处不再次调用整句分析模型。

处理顺序：独立限流 → 词典候选查询 → 模型根据原句与选中位置生成简短中文释义、必要的原形并选候选 ID → 运行时校验 → 返回统一结果。

结果包含：原词、start/end、本句中文释义、可空原形、可空音标、可空口音标签、词典来源与许可链接。模型返回的候选 ID 必须存在；候选选择失败时不显示音标。上下文无法可靠解释时返回明确失败，不能随意显示一个常用义。

词典不可达或无词条时允许模型只生成释义，音标必须为空；若模型也失败则返回查询失败。字典和模型响应均视为不可信数据，不执行其中的指令，不展示原始 HTML。

建议首版总时间预算 15 秒，其中词典阶段最多 5 秒，模型使用剩余预算；取消信号贯穿两阶段。无隐式自动重试，由用户点击重试。复用现有模型连接配置，但不复用整句分析的 30 秒超时和重试调用链。独立错误代码区分非法参数、超长词、限流、超时和查询失败。

`/api/word` 使用独立限流命名空间，建议每客户端每分钟 30 次；不得消耗整句分析的 10 次额度。现有 Redis 前缀写死为 `sentence-analysis`，接入时需要参数化前缀，并隔离内存实例和配置。可信代理识别按当前 Vercel 部署约定；其他平台需按实际代理配置适配。

客户端限流不能代替供应商出口限流。公开部署前增加词典请求共享预算，按供应商出口分组、UTC 整点小时计数，预算 900 次／小时预留余量；没有可靠出口分组信息时采用全应用共享预算。缓存命中不扣词典额度；预算耗尽或供应商返回 429 时降级为仅释义，不新增词典请求。共享状态不可用时停止外部词典请求，仍可尝试模型释义。单进程本地实验只记录调用次数，不代表已实现部署级保护。

## 6. 缓存与并发

首版上下文结果只保存在页面会话内存，不写浏览器持久存储或业务数据库。

- Key：精确原句、start/end、原词、目标语言和查询方案版本。不同句子、同句不同位置分别缓存。
- 完整成功结果有效期 30 分钟，最多 100 项；容量满后淘汰最久未使用项。
- 仅释义成功、音标缺失的部分结果最多保留 30 秒，并提供重试；超时、限流和其他失败不缓存。
- 同一 key 的进行中请求合并；切换词后旧请求不得更新当前浮窗。取消与请求编号检查共同使用。
- 普通词典数据可采用服务端有界内存缓存：精确查询词形、语言及供应商版本为 key，成功有效期 1 小时、最多 500 项；不含用户原句。来源、许可和署名随缓存一起保留。
- 普通词典缓存和上下文释义缓存分开，不跨位置复用模型的本句释义。服务端缓存丢失只降低命中率，不影响正确性。

## 7. 验收样例与标准

开发前建立至少 20 个“句子＋选中位置”的固定样例，涵盖以下情形；先验证数据与模型组合，再实现完整浮窗。

| 情形 | 必须验证 |
| --- | --- |
| She left because she was tired. / left | 释义为离开，不能误成左边 |
| Turn left at the corner. / left | 不能复用上一句的离开释义 |
| I saw a saw. / 两个 saw | 两个位置分别为看见和锯子，缓存独立 |
| I read every day. 与 I read it yesterday. | 读音与时态匹配；不能确定则不展示错误音标 |
| went、bought | 当前词形音标，必要时给出正确原形 |
| don't、John’s、well-known、US/us | 词边界、大小写与查询规范化正确 |
| 未收录词 | 无音标时明示缺失，不崩溃、不编造 |
| A→B 快速点击、加载中关闭、重新分析 | 无旧响应覆盖或浮窗重新弹出 |
| 同位置重复点击 | 有效缓存内不新增查询，过期后重新请求 |
| 服务超时与 429 | 可重试，整句结果保持完整 |
| 桌面键盘、390px 手机 | 可打开、阅读、关闭，无横向溢出 |

对固定样例逐项核对预期词义和允许的 IPA 候选。任何会混淆位置、显示错误音标或改变原文的问题都要修复后再上线；“暂无音标”必须作为降级结果单独统计，不能算音标准确命中。
